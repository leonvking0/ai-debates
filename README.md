# AI Debates

Multi-agent roundtable debates on complex, high-stakes topics — generated by AI agents arguing from distinct disciplinary perspectives.

## Purpose

Most AI-generated content is single-voice: one model, one perspective, one answer. Real intellectual progress comes from **structured disagreement** — forcing different frameworks to collide, stress-test each other, and surface blind spots that no single viewpoint catches.

This repo captures multi-agent debates where each AI agent embodies a specific persona with a defined worldview, expertise, and set of biases. The goal isn't consensus — it's **rigorous adversarial exploration** of ideas.

## Methodology

### Agents & Personas

Each debate assigns **3 AI agents** to distinct personas. Agents are backed by different models (Gemini, Claude, Codex/GPT) to maximize diversity of reasoning patterns:

| Role | Archetype | Lens |
|------|-----------|------|
| Agent 1 | Domain expert (e.g., economist) | Structural/systemic analysis |
| Agent 2 | Practitioner (e.g., investor) | Applied/market-facing perspective |
| Agent 3 | Technologist/builder | Implementation reality & technical constraints |

Personas are designed with **explicit frameworks and biases** — not to be "balanced," but to argue their position honestly while acknowledging where their model breaks down.

### Debate Structure

Each debate is divided into **thematic blocks** (typically 5-6), each covering a cluster of related questions.

Every block runs through two phases:

1. **Phase 1 — Opening Positions**: Each agent delivers an independent ~1,000-word argument on the block's questions. No cross-talk — pure parallel reasoning.
2. **Phase 2 — Cross-Examination**: Each agent reads the others' positions and responds — challenging assumptions, finding contradictions, building on agreements.

After both phases, a **moderator synthesis** identifies key agreements, disagreements, and open questions.

### Technical Execution

- Agents run via CLI tools (Gemini CLI, Codex CLI) in non-interactive mode
- Communication is **file-system-based** — no real-time chat, no prompt contamination
- Each agent receives the same context (topic + prior positions) but generates independently
- Different underlying models ensure genuine reasoning diversity, not just prompt variation

### [AI, Labor, Capital, and the Future of Economic Order](roundtable-ai-labor/)

*3 agents · 6 blocks · 30 questions · ~45,000 words*

A deep examination of how AI-driven automation may reshape labor markets, capital flows, geopolitics, and social order. Covers the demand problem, labor restructuring, political consequences, geopolitical dimensions, financial markets, and philosophical questions about human purpose in a post-labor economy.

**Personas:**
- 🏛️ **Dr. Wei** (Macro Economist) — Structural analysis, historical parallels, policy frameworks
- 💼 **Victoria Chen** (Capital Allocator) — Market dynamics, portfolio strategy, institutional incentives
- ⚡ **Samir** (Technologist) — Implementation timelines, technical constraints, builder perspective

## Contributing a New Debate

To add a new roundtable:

1. Create a directory under the repo root (e.g., `debate-topic-name/`)
2. Write a `full-session-prompt.md` defining the topic, personas, and question blocks
3. Run each block through the two-phase structure
4. Compile syntheses and commit

Built with [OpenClaw](https://github.com/openclaw/openclaw) + the `roundtable` skill.
